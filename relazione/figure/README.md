# Figure della relazione

Inserire qui gli export approvati in PDF vettoriale (preferito per i diagrammi),
PNG o JPG. I sorgenti PlantUML rimangono sotto `docs/diagrams/`.

Suddivisione consigliata quando arrivano le figure:
`use-cases/`, `mockup/`, `dominio/`, `stati/`, `architettura/`, `database/`, `sequenze/`, `test/`.

I futuri mockup sotto `mockup/` rappresenteranno una proposta visiva dell'interfaccia.
Associare ogni schermata a un ID (ad esempio MCK-01) e ai casi d'uso pertinenti;
documentare lo strumento e conservare gli export per l'inserimento nella relazione.

Annotare nella PR di integrazione il sorgente e il commit cui corrisponde ogni export.
Non sostituire le figure su cui stanno ancora lavorando i colleghi.
